Check your source code

Drop the folder (or a .zip) of your website's code. FlawRadar checks for exposed secrets, injection patterns, unsafe data flows, weak cryptography and risky configuration. Detection runs on the server so its rule implementation is not shipped to every visitor.

Source handling. Selected files are sent over HTTPS and analyzed in memory. FlawRadar does not write uploaded source files to disk or include raw file contents in reports. Dependency identifiers may be sent to public vulnerability databases for advisory matching. Secrets shown in findings are masked. Do not upload code you are not authorized to share with this service.

What this can and cannot do

  • It matches patterns line by line and tracks selected request-derived values through variables inside one file. It does not yet trace data across files or functions, and it cannot prove authorization logic.
  • Some matches are lookalikes. Each finding says how sure the rule is (high, medium or low confidence). Read the line before changing anything.
  • It looks up known vulnerabilities in dependencies via the OSV database when a lockfile or pinned requirements file is present. Coverage is not complete; also run npm audit, pip-audit or osv-scanner in CI.
  • A clean result means none of these patterns matched. It does not mean the code is secure.
