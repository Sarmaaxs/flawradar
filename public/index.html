Check your website's security

Enter an address. FlawRadar reads the site's certificate, headers, cookies and DNS records, then gives you a short list of fixes you can paste into your server configuration.

Scan a website

Only scan sites you own or have written permission to test. Testing a system without permission can be a crime in many countries, and you alone are responsible for your scans. Reports are information, not a guarantee that a site is secure.

Have code, not a live site?

Drop a folder or a .zip. FlawRadar looks for hard-coded secrets, injection and XSS patterns, and risky settings. Your code is not stored.

Check source code

How it works

  1. Type your site address and press Run scan. It takes about ten seconds.
  2. You get a grade from A to F and a short list of what to fix first, in plain words.
  3. Each problem comes with the exact setting to paste into your server. Download the report to keep or send to your developer.

Source languages and file formats

FlawRadar currently reads these source, script, markup and configuration formats. Detection is rule-based; coverage differs by language and file type.

Programming languages

JavaScript, TypeScript, Python, PHP, Ruby, Java, Go, C# and Shell scripts.

Web and templates

HTML, HTM, JSX, TSX, Vue, Svelte, EJS, Handlebars, Twig and PHTML.

Configuration and data

JSON, YAML, TOML, INI, CONF, CFG, CONFIG, ENV, Properties, .htaccess and text files.

Dependency checks

Node.js package manifests and lockfiles, plus pinned Python requirements files for known-vulnerability lookups.

C, C++, Rust and other formats are not currently listed as supported source-analysis languages. See source-code checks for current limits.
